# Model artifacts

Generated by the training steps in [docs/MODELS_AND_DATA.md](../docs/MODELS_AND_DATA.md#reproducing).

| File | Model | Tracked in git |
|---|---|---|
| `training_summary.json` | Classifier and retrieval run summary (macro F1, split, backend) | yes |
| `label_encoder.json`, `symptom_list.json` | Classifier labels (85 diseases) and features (166 symptoms) | yes |
| `disease_classifier.json` | XGBoost classifier | no (regenerate) |
| `disease_records.json`, `rag_config.json`, `disease_rag.index` / `disease_rag_vectorizer.pkl` | Retrieval records and index (TF-IDF in the shipped run) | config only |
| `ner-banglabert-medical/` | Fine-tuned BanglaBERT NER (tokenizer and config tracked; weights gitignored) | partly |
| `ner_training_summary.json` | NER run summary (F1 0.790 on silver validation) | yes |

The web app uses JSON exports of these, in `healthmax-ai-assistant/public/model/` (`scripts/export_browser_artifacts.py`).
